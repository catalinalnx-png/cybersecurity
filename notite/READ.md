# Cybersecurity Study Notes & Lab Documentation

This directory contains personal study notes, command cheat sheets, and step-by-step documentation gathered during cybersecurity labs, CTF challenges, and hands-on exercises.

## Topics Covered
* **Linux & Digital Forensics:** File system navigation, directory structuring, log inspection, and basic evidence handling.
* **Network Security:** Traffic analysis, packet inspection, firewall rules, and network reconnaissance.
* **System Administration & Hardening:** Windows/Linux environment configuration, permissions, and security baselines.
* **Malware & Log Analysis:** Identifying suspicious indicators, analyzing system events, and incident investigation workflows.

## Purpose
* Keep track of essential terminal commands and troubleshooting steps.
* Document findings and methodologies from practical labs.
* Serve as a quick reference guide for future projects and certifications.
