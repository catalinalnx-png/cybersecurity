# Analizor de loguri SSH cu AI

## Rulare
pip install -r requirements.txt
export ANTHROPIC_API_KEY=cheia_ta     # sau o introduci în interfață
streamlit run app.py

Apasă "Folosește logul de exemplu" sau încarcă propriul auth.log (/var/log/auth.log).
Fără cheie API, aplicația funcționează doar cu regulile (fără explicații AI).
